# Security Policy

## Reporting Security Issues

If you discover a security vulnerability, please email security@codexvisual.com instead of using the issue tracker.

## Supported Versions

| Version | Supported |
| --- | --- |
| Latest | ✅ Yes |
| Previous | ⚠️ Limited |
| Older | ❌ No |

## Security Best Practices

### For Users
- Keep dependencies updated
- Use strong passwords
- Enable two-factor authentication
- Don't share sensitive data

### For Contributors
- Don't commit sensitive information
- Use environment variables for secrets
- Follow secure coding practices
- Review security before submitting PRs

## Dependency Security

We regularly update dependencies and use security scanning tools.

## Responsible Disclosure

We appreciate responsible security researchers. Please allow time for us to fix vulnerabilities before public disclosure.
